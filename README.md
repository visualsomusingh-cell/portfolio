# TurboCraft — Maya Shankar's Portfolio

A single-page portfolio for Maya Shankar (Final Year CSE Student), designed in a Hot Wheels die-cast racing theme ("TurboCraft").

- **Design:** exported from [Stitch](https://stitch.withgoogle.com/) and kept as-is (layout, styling, components).
- **Content:** pulled from [`Maya_Shankar_Resume-1.pdf`](Maya_Shankar_Resume-1.pdf) — projects, education, skills, and contact info.
- **Stack:** static HTML + Tailwind (via CDN), no build step required.

## Structure

- `index.html` — the full one-page site (Hero, Garage/Projects, Telemetry/Skills, Track Record/Education, Pit Stop/Contact).
- `assets/img/` — hero and project images (mirrored locally from the Stitch export).
- `stitch-export/` — the original raw Stitch export, kept for reference.
- `Maya_Shankar_Resume-1.pdf` — the source resume, also linked as a downloadable CV on the site.

## Running locally

Just open `index.html` in a browser — no build step needed.
